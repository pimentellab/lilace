# compute negative control bias correction (intended for internal use)

compute negative control bias correction (intended for internal use)

## Usage

``` r
.correct_negative_control(mu, data, input, control_label, seed = NULL)
```

## Arguments

- mu:

  mu posterior samples

- data:

  data

- input:

  stan model input parameters

- control_label:

  control label

- seed:

  seed for negative control sampling
